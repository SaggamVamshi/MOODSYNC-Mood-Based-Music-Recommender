# 🎵 MoodSync - Mood-Based Music Recommender

MoodSync is a responsive web application that recommends music based on the user's selected or entered mood.

## Features

- 🎯 Mood selection
- ⌨️ Type your mood
- 🎵 Mood-based music recommendations
- ▶️ Play songs
- ❤️ Add songs to favorites
- 💾 LocalStorage for favorite songs
- 📱 Responsive design
- ✨ Smooth UI animations

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Mood Categories

- 😊 Happy
- 😢 Sad
- 😌 Calm
- 😨 Fear
- ❤️ Romantic
- ⚡ Energetic

## How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Open `index.html` with Live Server.
4. Select or type a mood.
5. Click **Find Music**.
6. Select a song and click **Play**.

## Project Purpose

The purpose of MoodSync is to provide a simple and interactive music recommendation experience based on the user's current mood.
